Lucid Pair

ローカル優先のデスクトップ AI 秘書 / Windows 11・x64 ・ 運営者: yama9108(個人)

一言で: 取得したデータは原則として自分の端末内で管理します。 外部に送るのは「利用者が自分で OAuth で接続したサービス」「利用者が AI を有効にした場合の AI 処理先」 「利用者が有効にした場合の SMTP 送信先」だけです。開発者のサーバーには送信しません (OAuth 連携も利用者の端末上で動作します)。

主な機能

  • 作業の「後回し」 — ボタンを押した瞬間の画面・作業場所・予定を記録して タスク化し、期限の 5 分前にリマインドします。記録したスクリーンショットと詳細は タスク画面からいつでも閲覧できます。
  • 画面分析オーバーレイ — 作業中のウィンドウの文字や操作画面を分析し、 その位置にマーキングと吹き出しを重ねます(クリックは透過)。
  • 予定のリマインド — 予定は 10 分前、予定のリマインドは設定時刻どおりに通知します。
  • 外部サービスの監視 — Google カレンダー / Microsoft 365 (Outlook・OneDrive・Teams)/ Discord などを、利用者が接続したものだけ読み取ります。 公式 API がないサービスも、利用者が有効にした場合に 指定した定点領域の画面キャプチャ(保存なし)で監視できます。
  • 作業員モード(サンドボックス) — 実行は許可リストと信頼ディレクトリ内に限定され、 外部操作は承認ゲートを通ります。

Google API Services User Data Policy への準拠

Lucid Pair's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

参照: Google API Services User Data Policy / OAuth 2.0 Policy

Google API から取得したデータを広告に使わず、人が直接精査する用途にも使わず、 AI モデルの学習データとしても使用しません。 また、Google のメール・予定を外部の AI へ送ることもありません (端末内のルールベース処理のみで処理します)。詳細は 個人情報対策(Privacy policy)に記載しています。

動作環境・配布

  • Windows 11 / x64。ポータブル zip(インストール不要)で配布しています。
  • 初回起動時にセットアップ画面(3D シーン)を表示します。Gemini API キーは任意です。
  • Google 連携を使う場合は、公式の Google ログイン画面で同意してください。 パスワードが Lucid Pair に入ることはなく(PKCE でトークンのみを交換)、 付与するスコープは同意画面で確認できます。
  • SMTP 通知を使う場合のみ、利用者が自分の設定ファイル(環境変数)にメールサーバーの情報を記載します (既定で無効。アプリの画面から入力する項目ではありません)。
